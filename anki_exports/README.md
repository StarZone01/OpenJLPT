# Japanese JLPT N5 + N4 Anki exports

Complete source lists:
- Vocabulary: 674 N5 + 630 N4
- Kanji: 84 N5 + 169 N4
- Grammar: 81 N5 + 98 N4

Import each TSV into Anki as a Basic note type. Use tab as the field separator, map columns to Front, Back and Tags, and enable HTML in fields. Each row becomes one card. Vocabulary and kanji include recognition, recall and listening cards; grammar includes recognition and recall.

Audio uses Anki's built-in Japanese TTS markup and is generated during review; a Japanese TTS voice must be installed. No native-speaker recordings are embedded.

Memory cues are original prompts generated for this export, not WaniKani mnemonics or etymological claims.
